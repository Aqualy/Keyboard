# GMK67 Configurator

A responsive 3D configurator for the GMK67 mechanical keyboard. Rotate and zoom the board, customise it,
then press **Test** to try your build in a short typing test.

Built with Vite, React, TypeScript, React Three Fiber and three.js.

## Getting started

Requires Node 22.12 or newer (`.nvmrc` pins the version used in CI).

```sh
npm install
npm run dev
```

## How it works

- `src/data/layout.gmk67.json` describes the 66 keys and is generated by `tools/make-layout.mjs`. Both the
  app and the Blender script read it.
- `tools/blender/build_gmk67.py` builds every model, the baked shadow and the environment map.
- `src/scene` holds the 3D scene. `KeyboardRig` owns the objects, and colours are shared uniforms, so a
  change is one tween rather than a material rebuild.
- `src/state` holds the build and stage state. A build is mirrored into the URL, so reloading keeps it.
- Key sounds are recordings played through `src/audio`. Plates reshape them with pitch and filtering.
